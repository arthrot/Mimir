# Moolah — Game Development Control Plane

Moolah is a local-first, engine-neutral knowledge and workflow layer for game development. It connects design documents, lore, source code, assets, decisions, Git history, tests, and production workflows so a developer can ask:

- What is authoritative?
- What changed, and what else does it affect?
- What should I do next?
- Which gate or convention am I missing?
- What evidence supports this answer?

The first working adapter targets the existing Samskara Unity project. The core is deliberately independent of Unity. An Unreal adapter is a first-class commercial target, not a fork of the product.
